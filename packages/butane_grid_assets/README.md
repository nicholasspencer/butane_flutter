# butane_grid_assets

Private Grid assets for Butane's cross-station Bluetooth burn workflow.

The package owns the `burn-host` and `burn-follower` orders, follower launchers,
station composition, and the scripted two-drive burn scenarios used to validate
real Butane applications across supported platforms.

It is distributed to trusted station consumers from the
`butane_grid_assets-v<version>` Git tag and is not published on pub.dev.
